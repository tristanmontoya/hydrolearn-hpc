# Rubric: Parallel Calibration of a Lumped Hydrologic Model

| Associated Learning Objectives                                                       | Criteria                                                      | Level #1 (Does Not Meet Expectations) (1 pt)                                                                                                 | Level #2 (Meets Expectations) (3 pts)                                                                                                                                                                                                                                  | Level #3 (Exceeds Expectations) (5 pts)                                                                                                                                                                                                                                                                |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| LO1: Analyze computational structure to design scalable parallel execution strategy. | Criterion #1: Analyze calibration workflow structure          | Fails to correctly describe serial calibration workflow; does not identify independent model evaluations as the opportunity for parallelism. | Accurately describes the OSTRICH–SUMMA workflow; explains why more Slurm tasks don't speed up serial optimization; identifies model evaluations as parallelizable with algorithm change to allow multiple candidates to be evaluated at the same time.                 | Provides sophisticated analysis of the workflow structure (e.g., the distinctions between serial and parallel DDS algorithm structure, the roles of the coordinator and worker MPI ranks, and how worker count and evaluation completion order affect the search trajectory).                          |

| LO3: Assess strategies in terms of speedup and efficiency, and interpret results.    | Criterion #3: Evaluate calibration scaling performance        | Performance table missing or contains major errors; analysis fails to address speedup, efficiency, or varying KGE' values.                   | Uses appropriate resource and timing measurements to report total MPI tasks, model-evaluation workers, runtime, speedup, efficiency, and best KGE'; calculates the metrics correctly; accurately characterizes the measured scaling; explains relevant limiting factors and variation in KGE' values. | Provides nuanced analysis connecting variability of candidate runtimes to interpretation of efficiency (i.e., explains how this is not, strictly speaking, a true strong scaling test); offers sophisticated assessment of sources of inefficiency and tradeoffs encountered in parallel calibration. |
